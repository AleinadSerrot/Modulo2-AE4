# Modulo2-AE4
módulo 2: actividad del aprendizaje esperado 4

INSTRUCCIONES
1) barra de navegación: implementar una navbar fija en la parte superior con enlaces para las secciones INICIO, ACERCA DE, CONTACTO; incluir un logotipo o título del lado izquierdo de la barra
2) encabezado principal: utiliza un contenedor de Bootstrap con un texto destacado que dé la bienvenida al usuario, destacando la misión del negocio.
3) sección e contenido: divide el contenido principal en tres columnas, utilizando el sistema de grillas de Bootstrap; cada columna debe tener un encabezado, un breve texto descriptivo y un botón con estilo Bootstrap.
4) formulario de contacto: agregar formulario sencillo con los siguientes campos: nombre, correo electrónico y un área de texto para los comentarios; incluir un botón de envío estilizado con Bootstrap.
5) pie de página: añadir un footer entrado n un texto de derechos reservados
6) estilizar y organizar: utilizar contenedores lases Bootstrap (container, row, col, bn, etc....) para organizar y estilizar el contenido; diseño responsivo a diferentes tamaños de pantalla
